# Ahmed El.Biany - Personal Portfolio

Static website (HTML/CSS/JS) ready for GitHub Pages.

## Structure
- `index.html` main page
- `css/style.css` styles
- `js/main.js` scripts (videos, settings such as WhatsApp number at the top)
- `assets/` profile photo (transparent) and favicon

## Deploy on GitHub Pages
1. Create a new repository and upload all files (index.html must be in the root).
2. Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / `(root)` > Save.
3. Your site will be live at `https://USERNAME.github.io/REPO-NAME/`.

Note: YouTube videos play only when the site is served over https (GitHub Pages) - not when opening the file directly from disk.
